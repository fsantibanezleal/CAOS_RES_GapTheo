# Canonical use cases

The twelve-case matrix spans six irrational baselines, one small-N case, one near-rational conditioning case, two rational collision cases, and two alternative allocators.

## Coverage goals

- Quadratic, transcendental-like, and phase-shifted angle declarations.
- N below, near, and beyond informative convergent denominators.
- Exact rational periods with repeated points.
- Deterministic non-arithmetic controls.

The machine-readable source is `data/input/canonical-scenarios.json`. The generated evaluation is `data/artifacts/benchmark.json`.
