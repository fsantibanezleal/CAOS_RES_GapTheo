# Run an experiment

Open the App route, choose a canonical scenario, then change alpha, N, phase, beta, process, or seed. The selector deep-links the canonical origin with `?case=<id>`. Parameter changes intentionally diverge from that preset.

Read the status before interpreting a view. Certified applies only to the declared irrational rotation regime. Boundary marks rational or collision-prone input. Contrast marks a non-rotation allocator.
