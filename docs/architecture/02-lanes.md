# Computation lanes

The live TypeScript lane supports immediate bounded interaction. The Python reference lane runs named ingest, preprocess, dataset, feature, registry, inference, evaluation, export, and validation stages. The replay lane serves committed JSON evidence.

There is no learned-model training stage. The registered methods are exact or numerical mathematical procedures, so fabricating checkpoints or predictive metrics would be scientifically irrelevant.

Cross-lane checks compare the unit-circle partition sum, gap count, additive residual, return-gap bound, discrepancy, and deterministic hash.
