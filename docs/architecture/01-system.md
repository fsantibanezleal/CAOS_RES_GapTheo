# System

The React application owns the bounded interactive experiment. `computeCertificate` normalizes input, allocates points, sorts the circle partition, groups lengths, evaluates the theorem boundary, and derives explanatory views. Stable point and gap identifiers keep animation, selection, words, and topology synchronized.

The CAOS shell owns the six public routes, bilingual state, theme state, architecture dialog, and product footer. The App route is an instrument surface; the other five routes are deep reading surfaces.

Is: a deterministic static research application. Is not: a formal proof assistant, irrationality test, or general topology package.
