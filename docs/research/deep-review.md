# GapTheo deep review

Research snapshot: 13 September 2026.

This note records the mathematical scope, state of the art, and novelty
boundary behind GapTheo. It is intentionally paired with the executable
certificate lane and the manuscript source. The app is a visual research
instrument: it exposes a direct finite calculation, derived explanations,
and explicit counter-regimes so that a visitor can inspect where the
three-gap theorem applies and where it does not.

## 1. Mathematical contract

For an irrational \(\alpha\in\mathbb R\setminus\mathbb Q\), consider the first
\(N\) fractional parts

\[
  \{0\alpha\},\nobreak\{1\alpha\},\ldots,\nobreak\{(N-1)\alpha\}\in\mathbb R/\mathbb Z.
\]

After sorting the points around the unit circle, the consecutive circular
gaps have at most three distinct lengths. In the three-length regime, the
largest length is the sum of the other two. The statement is finite in its
output but depends on the irrational-rotation hypothesis; a decimal control
cannot certify irrationality. GapTheo therefore keeps three facts separate:

1. the normalized numeric input;
2. the direct sorted-orbit certificate actually computed for the selected
   finite \(N\);
3. the theorem status, which is only certified for the declared irrational
   rotation mode.

Rational \(p/q\) input is shown as a periodic boundary case. Seeded random,
farthest-point, and two-frequency modes are contrast experiments, not theorem
inputs. This boundary is part of the product rather than a footnote.

## 2. Source review

### Classical and exact finite descriptions

- [Wikipedia, Three-gap theorem](https://en.wikipedia.org/wiki/Three-gap_theorem)
  provides an accessible overview and the standard names: three-distance,
  three-length, and three-gap theorem.
- [Hamada, arXiv:2308.11999](https://arxiv.org/abs/2308.11999) gives a modern
  geometric treatment of the finite orbit, including the alpha-height/Farey
  description and explicit formulas for the possible lengths and their
  multiplicities. It is the main source for the Farey / continued-fraction certificate lane.
- [Berthé and Reutenauer, HAL: hal-04769002](https://hal.science/hal-04769002)
  develops a word-theoretic and arithmetic framework around three-distance
  phenomena. The repository records the HAL metadata and uses the paper as a
  source for the combinatorial boundary, while the app does not claim to
  reproduce every result in that article.
- [Alessandri and Berthé, Three-distance theorem](https://www.irif.fr/~berthe/Articles/3d.pdf)
  is the principal compact reference for continued fractions, gap words, and
  the relation between the direct partition and symbolic descriptions.

### Dual, dynamical, and geometric viewpoints

- The return-time or dual mode changes the question from “what are the gaps
  between orbit points?” to “what are the index gaps between visits to a
  target interval?” It is presented as a related certificate with its own
  target interval and regime controls, not as a relabelled copy of the direct
  calculation.
- [Marklof and Strömbergsson, spaces of lattices](https://arxiv.org/abs/1304.3363)
  motivates the lattice-space panel. The panel is a geometric schematic that
  displays the active integer vectors and shortest-vector intuition; it does
  not replace the direct proof certificate.
- [Taha, interval exchanges and zippered rectangles](https://arxiv.org/abs/1503.02272)
  motivates the two-interval-exchange panel. A rotation is an especially
  structured two-interval exchange, which makes the symbolic and geometric
  relation visible without asserting that every interval exchange obeys the
  three-gap bound.
- [Haynes and Marklof, higher-dimensional gap distributions](https://arxiv.org/abs/1301.4338)
  and [Berthé and Kim, higher-dimensional extensions](https://arxiv.org/abs/1504.01975)
  motivate the explicit two-frequency contrast. Higher-dimensional problems
  have different distance-count behavior, so GapTheo labels them as
  extensions rather than silently generalizing the one-dimensional theorem.
- [Dasgupta and Roeder, gap-word symmetries](https://arxiv.org/abs/1502.04699)
  motivates the cyclic-word and symmetry inspector. The app exposes the word
  generated by the direct gap ordering and states which observations are
  exploratory rather than formal classification claims.
- [Suárez-Salas and Perea, topology and circle samples](https://arxiv.org/abs/2306.08826)
  motivates the finite zero-dimensional Rips lens. The topology tab tracks
  connected-component merges as the threshold passes the observed gap values;
  it is deliberately bounded to \(H_0\), not a claim of general persistent
  homology.

### Formal verification and public demonstrations

- [Mayero, Coq formalization](https://www.irif.fr/~mayero/three-gap/)
  demonstrates that a formal proof lane is possible and clarifies the
  distinction between a checked theorem and a visualization.
- [Lean Three Gap Theorem project](https://github.com/fpvandoorn/three-gap-theorem)
  is a useful current formalization reference. GapTheo does not claim Lean or
  Coq certification because no checked proof artifact is shipped in this
  release.
- [Wolfram Demonstrations Project](https://demonstrations.wolfram.com/ThreeGapTheorem/)
  and [CGViz](https://cg-viz.com/three-gap-theorem/three-gap-theorem.html)
  show the value of interactive circle plots. GapTheo extends that genre with
  synchronized certificates, research-source annotations, contrast methods,
  route-level documentation, and reproducible JSON artifacts.

## 3. State-of-the-art assessment

The literature already provides several strong ingredients, but they are
usually separated by purpose:

| Layer | Established capability | GapTheo treatment |
| --- | --- | --- |
| Direct theorem | Sort the orbit and count at most three lengths | Live direct oracle with visible residual checks |
| Arithmetic certificate | Farey intervals, convergents, exact candidate lengths | Farey / continued-fraction certificate tied to the current \(\alpha\) and \(N\) |
| Symbolic dynamics | Cyclic words and substitutions/symmetries | Gap word, genealogy, and symmetry probe |
| Dual dynamics | Return-time/target-interval theorem | Separate Return Gaps workbench |
| Geometry | Lattice and interval-exchange interpretations | Linked schematic lenses with boundary labels |
| Topology | Component filtration of a finite circle sample | Bounded 0D Rips view tied to actual observed gaps |
| Reproducibility | Formal proofs and isolated demonstrations | Versioned scenario/certificate contracts, deterministic fixtures, manuscript |
| Scope control | Hypotheses are often implicit in demos | Rational, random, farthest, and two-frequency contrasts are explicit |

The product contribution is therefore integration and inspectability, not a
new theorem. A user can move from a point insertion to the final sorted gaps,
then to a Farey bracket, continued-fraction data, a return-time experiment,
and a topology or lattice lens without losing the identity of the underlying
scenario. The app also makes the failure of an over-generalized statement
visible.

## 4. Novel demonstration proposal and result

The novel demonstration is a synchronized **certificate atlas** with four
linked observations:

1. **Orbit geometry.** The circle shows the actual finite orbit and the
   animated insertion order. Each gap is a stable object with a length,
   multiplicity, and lineage entry.
2. **Arithmetic event geometry.** The Farey / continued-fraction certificate shows the current Farey
   bracket, candidate lengths, multiplicities, convergents, and the changing
   combinatorial regime as the user moves \(\alpha\) or \(N\).
3. **Dual and topological readings.** The same experiment can be re-read as
   target-interval return indices or as the threshold filtration of connected
   components on the sampled circle.
4. **Adversarial contrast.** The farthest-point allocator chooses the next
   point from the largest uncovered arc, while seeded random placement and a
   two-frequency sequence provide additional non-theorem regimes. The UI
   keeps these panels visually comparable but mathematically labels them as
   contrasts.

This is a novel product-level demonstration in the modest, defensible sense
of a reproducible visual protocol. It is not a new mathematical theorem,
proof, classification, or formal verification result. The manuscript uses the
same wording and documents the non-claims.

## 5. Demonstration methods

The Explore workbench supports these methods:

- **Arithmetic rotation:** \(x_n=\{\phi+n\alpha\}\), the canonical theorem
  process. The angle step, phase, \(N\), and rational/irrational declaration
  are editable.
- **Seeded random:** a deterministic pseudorandom placement for comparing
  gap counts and spatial statistics. The seed is part of the certificate.
- **Farthest-point allocator:** start with a seed set and repeatedly place the
  next point in a largest currently empty arc. This realizes the requested
  “far from existing content” method and is intentionally flagged as outside
  the rotation theorem.
- **Target-interval return mode:** choose a \(\beta\)-interval and inspect visit
  indices, return gaps, and the two/three-regime badge.
- **Two-frequency extension:** inspect \(\{n\alpha+m\beta\}\) as a changed
  sequence class. It is not presented as a one-dimensional rotation orbit.

Every mode uses deterministic controls where randomness is involved. The
Python reference lane generates canonical JSON certificates; the TypeScript
live lane recomputes the current finite state in the browser rather than
silently replacing controls with a pre-rendered picture.

## 6. Validation and limitations

The public repository includes JSON schemas, canonical scenarios, generated
artifacts, a Python reference lane, TypeScript tests, and the manuscript source.
The validation contract checks deterministic content hashes, point/gap
consistency, theorem status, and contrast boundaries. The production release
is static and client-side, which is appropriate for the bounded finite
workbench; it does not claim a server-side exact-arithmetic service.

Known boundaries remain visible:

- finite decimal input does not prove irrationality;
- finite numerical grouping uses a documented tolerance;
- rational inputs are periodic boundary cases;
- the topology lens is finite \(H_0\)/0D Rips only;
- the lattice and interval-exchange views are explanatory geometric lenses;
- the two-frequency view does not inherit the three-gap theorem;
- no Coq/Lean artifact is claimed by this release.

## 7. Reproducibility path

From the repository root:

```text
python data_pipeline/run.py
python scripts/validate_artifacts.py
npm run typecheck
npm run test
npm run build
```

The static Pages deployment runs the same artifact-generation and validation
steps before uploading the frontend bundle. The custom domain is represented
both by `frontend/public/CNAME` and by the GitHub Pages custom-domain setting.
The release evidence is kept in the deployment documentation and the public
workflow history.
