# Frameworks

GapTheo uses a deliberately small stack:

- React and TypeScript for deterministic browser state.
- The CAOS app shell for product-level navigation and accessibility controls.
- KaTeX for mathematical notation.
- Vite for the static production bundle and Vitest for browser-engine tests.
- Python standard library for the reference evidence pipeline.

See [browser framework](01-browser.md), [CAOS shell](02-caos-shell.md), and [reference pipeline](03-python-reference.md).
