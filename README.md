# GapTheo

GapTheo is a public CAOS research app for exploring the three-gap theorem
through exact finite orbits, Farey cells, continued fractions, return times,
cyclic words, lattice geometry, and topology.

Live site: https://gaptheo.fasl-work.com/

## What the app demonstrates

For an irrational rotation alpha, the points {n alpha} on the unit circle
have at most three consecutive gap lengths. When three occur, the largest is
the sum of the other two. GapTheo keeps the direct sorted-orbit calculation
visible while synchronizing derived certificates and visual explanations.

The farthest-point allocator, seeded random placement, and two-frequency
sequences are deliberate contrast experiments. They are not inputs to the
classical theorem and are labelled accordingly.

## Run locally

Requirements: Node 20 or later, npm 10 or later, and Python 3.11 or later.

    npm install --prefix frontend
    npm run generate
    npm run dev

The browser workbench runs entirely client-side. Canonical replay artifacts
are generated by the Python reference lane and checked into
frontend/public/artifacts.
