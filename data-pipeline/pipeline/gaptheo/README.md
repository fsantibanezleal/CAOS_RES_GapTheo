# GapTheo deterministic computation

This package contains GapTheo's deterministic finite-rotation reference engine. The sorted-orbit computation is the finite numerical oracle; Farey and continued-fraction descriptions provide arithmetic cross-checks. Seeded farthest-point and random allocations are comparison processes, not instances of the three-gap theorem.

No learned model is applicable. The pipeline records the direct certificate and evaluates theorem, boundary, and contrast regimes without fitting a model. A finite decimal calculation cannot establish irrationality.
